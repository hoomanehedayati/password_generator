
# Password Generator

This project is a simple password generator made with Python.

## Features
- Allows the user to insert their own password.
- Checks password strength.
- Generates a new password if the entered password is not strong enough.
- Generates passwords with uppercase letters, lowercase letters, numbers and special characters.
- Allows the user to encrypt the password using Caesar Cipher.

## Files
- `main.py`: Runs the program.
- `passgen.py`: Contains the password generator, password strength checker and Caesar Cipher functions.

## How to Run
1. Make sure Python is installed.
2. Keep `main.py` and `passgen.py` in the same folder.
3. Run the following command:

```bash
python main.py
```

## Requirements
- Python 3
- No external libraries required.
